# Inctagram Frontend

Frontend application for Inctagram social network.

This project is built with Next.js using the App Router.

## Tech Stack

- Next.js
- React
- TypeScript
- CSS Modules
- ESLint
- pnpm

## Prerequisites

- Node.js
- pnpm 11.23.0

## Getting Started

### Install dependencies

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000)
in your browser to see the application.

If port 3000 is already in use, check the terminal
for the available port.

The main page is located at `src/app/page.tsx`.

## Available Commands

| Command | Description |
| --- | --- |
| `pnpm install` | Install project dependencies |
| `pnpm dev` | Start the development server |
| `pnpm build` | Create a production build |
| `pnpm start` | Start the production server after building |
| `pnpm lint` | Run ESLint checks |
